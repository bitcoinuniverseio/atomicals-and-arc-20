Todos os guias aqui seguem a mesma estrutura, para que saiba sempre o que vai fazer antes de o
fazer.

| Seccao | O que lhe diz |
| --- | --- |
| Antes de comecar | Pre-requisitos, redes suportadas e estado de suporte atual |
| O que precisa | Entradas exatas |
| O que acontece | Saidas esperadas e o que a sua carteira vai perguntar |
| Custo | Comportamento das taxas para esta acao especifica |
| Verifique antes de assinar | As verificacoes de seguranca para esta acao |
| Se falhar | Casos de falha nomeados e o que cada um significa |
| Depois de difundir | Como verificar o resultado, e consideracoes de reorganizacao |
| Fonte | A pagina normativa por tras do procedimento |

Nunca partilhe uma frase semente, uma chave privada ou um ficheiro de exportacao da carteira. Nunca
deixe uma carteira Bitcoin generica escolher entradas de taxa a partir de um conjunto que inclua as
suas saidas coloridas.
