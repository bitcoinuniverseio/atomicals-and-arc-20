| 章節 | 它告訴你什麼 |
| --- | --- |
| 開始之前 | 前置條件、支援的網路以及目前的支援狀態 |
| 你需要什麼 | 確切的輸入 |
| 會發生什麼 | 預期輸出，以及錢包會詢問什麼 |
| 成本 | 這項具體操作的手續費行為 |
| 簽署前檢查 | 這項操作的安全檢查 |
| 如果失敗 | 具名的失敗情形及其含義 |
| 廣播之後 | 如何驗證結果，以及重組方面的注意事項 |
| 來源 | 支撐該步驟的規範頁面 |
