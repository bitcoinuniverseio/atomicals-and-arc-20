ここにあるガイドはすべて同じ構成です。実行する前に、これから何をするのかが必ず分かります。

| 節 | 内容 |
| --- | --- |
| 始める前に | 前提条件、対応ネットワーク、現在のサポート状況 |
| 必要なもの | 正確な入力 |
| 何が起きるか | 想定される出力と、ウォレットが尋ねてくる内容 |
| 費用 | この操作に固有の手数料の挙動 |
| 署名前の確認 | この操作の安全確認 |
| 失敗した場合 | 名前の付いた失敗ケースと、それぞれの意味 |
| ブロードキャスト後 | 結果の確認方法と、再編成に関する注意 |
| 出典 | 手順の根拠となる規範ページ |

シードフレーズ、秘密鍵、ウォレットのエクスポートファイルを共有しないでください。色付きの出力を含む
集合から、汎用の Bitcoin ウォレットに手数料用の入力を選ばせないでください。
