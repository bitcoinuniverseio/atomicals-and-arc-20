    Why it does not send requests

    An explorer that sends requests needs a credential in the page and an origin to point at. Both are mistakes: the credential ends up in browser history and logs, and the origin becomes a default someone points production traffic at.

    So this explorer renders the contract and hands you a command. You choose the origin and supply the credential in your own environment.

    Reading a mutation

    Section titled “Reading a mutation”

    Mutations are marked. Before building one, read:

    • Authentication for the signature material and headers.
    • Idempotency and request IDs for safe retries.
    • Marketplace v1 for the exact protocol data shapes.

    The copied command carries placeholders for the idempotency key and the body, because the signature covers the exact body bytes. Re-serialising the body invalidates it.
