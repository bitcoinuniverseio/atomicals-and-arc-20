    What this documentation is

    Section titled “What this documentation is”

    ARC-20 is the Atomicals fungible token model on Bitcoin. One unit is one coloured satoshi. Atomicals also covers non-fungible objects, Containers, DMINT collections, Realms, Subrealms, and Paynames. All of it lives in ordinary Bitcoin transactions and is interpreted by an Atomicals validator.

    Three things follow from that, and this site never blurs them:

    Protocol behavior
    What a pinned Atomicals validator does
    Universe implementation
    What our services expose today
    Proposed or beta
    What exists but is not live

    A protocol capability is not automatically a product feature. A product feature is not automatically protocol behavior. Every page states which layer it describes, at which source revision, and when that was last checked.
