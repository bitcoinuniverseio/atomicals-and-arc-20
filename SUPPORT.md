# Support

- Documentation site: https://bitcoinuniverseio.github.io/atomicals-and-arc-20/
- Central documentation portal: https://docs.bitcoinuniverse.io
- Questions or corrections about these documents: open a GitHub issue on this
  repository.
- Security-sensitive reports: see [SECURITY.md](SECURITY.md) and use private
  vulnerability reporting, never a public issue.
- Bitcoin Universe product questions (marketplace, wallet, Inscribe): use the
  support channels listed at https://docs.bitcoinuniverse.io.
- Upstream Atomicals protocol questions: https://github.com/atomicals is the
  upstream organization. This site documents the protocol as indexed by
  Bitcoin Universe.
