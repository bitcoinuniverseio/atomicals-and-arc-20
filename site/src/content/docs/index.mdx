## What this documentation is

ARC-20 is the Atomicals fungible token model on Bitcoin. One unit is one coloured satoshi.
Atomicals also covers non-fungible objects, Containers, DMINT collections, Realms, Subrealms,
and Paynames. All of it lives in ordinary Bitcoin transactions and is interpreted by an
Atomicals validator.

Three things follow from that, and this site never blurs them:

automatically protocol behavior. Every page states which layer it describes, at which source
revision, and when that was last checked.

## Built for machines too

Every page has a raw Markdown twin, a stable page ID, and a source record. The site also
publishes `llms.txt`, `llms-full.txt`, a page manifest, JSON Schemas, OpenAPI documents, and a
read-only MCP server so an agent can read this documentation without scraping HTML.

See [AI and agent access](reference/ai-access/).

## What we will not tell you

No price talk. No rankings. No investment, legal, or tax advice. No claim that a ticker proves
who made something, that metadata proves authenticity, or that a marketplace listing proves
ownership. Where evidence is missing, the page says so instead of guessing.
