faire avant de le faire.

| Section | Ce qu elle vous dit |
| --- | --- |
| Avant de commencer | Prerequis, reseaux pris en charge et etat du support actuel |
| Ce dont vous avez besoin | Entrees exactes |
| Ce qui se passe | Sorties attendues et ce que votre portefeuille va demander |
| Cout | Comportement des frais pour cette action precise |
| Verifiez avant de signer | Les verifications de securite pour cette action |
| En cas d echec | Cas d echec nommes et ce que chacun signifie |
| Apres diffusion | Comment verifier le resultat, et considerations de reorganisation |
| Source | La page normative derriere la procedure |
