这里的每一篇指南结构一致，让你在动手之前就清楚将要做什么。

| 章节 | 它告诉你什么 |
| --- | --- |
| 开始之前 | 前置条件、支持的网络以及当前支持状态 |
| 你需要什么 | 确切的输入 |
| 会发生什么 | 预期输出，以及钱包会询问什么 |
| 成本 | 这一具体操作的手续费行为 |
| 签署前检查 | 这一操作的安全检查 |
| 如果失败 | 具名的失败情形及其含义 |
| 广播之后 | 如何验证结果，以及重组方面的注意事项 |
| 来源 | 支撑该步骤的规范页面 |
