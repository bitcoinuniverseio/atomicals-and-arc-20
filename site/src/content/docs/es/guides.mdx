Todas las guias aqui siguen la misma estructura, para que siempre sepas que vas a hacer antes de
hacerlo.

| Seccion | Que te dice |
| --- | --- |
| Antes de empezar | Requisitos previos, redes soportadas y estado de soporte actual |
| Que necesitas | Entradas exactas |
| Que ocurre | Salidas esperadas y que te va a preguntar tu billetera |
| Coste | Comportamiento de las comisiones para esta accion concreta |
| Comprueba antes de firmar | Las comprobaciones de seguridad para esta accion |
| Si falla | Casos de fallo nombrados y que significa cada uno |
| Despues de difundir | Como verificar el resultado, y consideraciones de reorganizacion |
| Fuente | La pagina normativa detras del procedimiento |

<Aside type="danger" title="Dos reglas que nunca cambian">
Nunca compartas una frase semilla, una clave privada o un archivo de exportacion de billetera.
Nunca dejes que una billetera Bitcoin generica elija entradas de comision de un conjunto que
incluya tus salidas coloreadas.
</Aside>
