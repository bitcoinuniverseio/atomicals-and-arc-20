Every guide here follows the same shape, so you always know what you are about to do before you
do it.

| Section | What it tells you |
| --- | --- |
| Before you start | Prerequisites, supported networks, and current support status |
| What you need | Exact inputs |
| What happens | Expected outputs and what your wallet will ask |
| Cost | Fee behavior for this specific action |
| Check before signing | The safety checks for this action |
| If it fails | Named failure cases and what each means |
| After broadcast | How to verify the result, and reorg considerations |
| Source | The normative page behind the procedure |

<Aside type="danger" title="Two rules that never change">
Never share a seed phrase, private key, or wallet export file. Never let a general purpose Bitcoin
wallet select fee inputs from a set that includes your coloured outputs.
</Aside>
