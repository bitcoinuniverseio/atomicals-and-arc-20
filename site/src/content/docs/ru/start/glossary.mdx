Термины этого глоссария используются на всём сайте и во всех переводах. Идентификаторы кода, имена
свойств схем, имена операций и хеши никогда не переводятся.

## Основа

**Atomical**
: Цифровой объект, созданный транзакцией Bitcoin и переносимый выходом Bitcoin.

**Atomical ID**
: Постоянный идентификатор Atomical вида `<txid>i<индекс-выхода>`. Назначается один раз и не меняется.

**Номер Atomical**
: Последовательный номер, присваиваемый в порядке выпуска. Удобен для отображения, но хранить нужно не его.

**Расположение**
: Непотраченный выход, который сейчас несёт Atomical. Меняется при каждом перемещении.

**Оболочка**
: Структура скрипта в свидетеле, несущая `atom`, операцию и payload в CBOR внутри транзакции reveal.

**Операция**
: Короткий код внутри оболочки, сообщающий валидатору, что делать. Примеры: `ft`, `dft`, `dmt`, `nft`, `mod`, `sl`.

**commit и reveal**
: Схема из двух транзакций. commit платит на выход Taproot, reveal тратит его и раскрывает оболочку.

**Bitwork**
: Требование к префиксу идентификатора транзакции в духе доказательства работы, ограничивающее выпуски и заявки.

**Кандидат**
: Ожидающая заявка на глобально распределяемое имя или тикер, до того как правила определят победителя.

**Проверенный победитель**
: Atomical, который правила признали держателем имени или тикера.

**Поколение**
: Неизменяемый снимок индекса в согласованной позиции цепочки.

**Реорганизация**
: Реорганизация цепочки Bitcoin, способная сделать ранее проиндексированные результаты недействительными.

## ARC-20

**ARC-20**
: Модель взаимозаменяемых токенов Atomicals. Одна единица это один окрашенный сатоши.

**Тикер**
: Глобально распределяемое имя ARC-20. Не доказательство личности создателя.

**Окрашенная UTXO**
: Выход Bitcoin, который валидатор признаёт несущим величину ARC-20.

**Кардинальная UTXO**
: Обычный выход Bitcoin без величины Atomicals. Используется для комиссий и сдачи.

**Прямой FT**
: Одношаговый выпуск `ft`, помещающий всё предложение в нулевой выход.

**DFT**
: Развёртывание децентрализованного взаимозаменяемого токена, созданное через `dft`.

**Заявка DMT**
: Один выпуск против развёртывания DFT с помощью операции `dmt`.

**Бессрочный DFT**
: Децентрализованный режим, зависящий от активации, с нарастающим Bitwork и необязательным общим пределом.

**Величина выпуска**
: Точная величина в сатоши, которую каждая корректная заявка DMT помещает в нулевой выход.

**Максимум выпусков**
: Число корректных заявок в фиксированном режиме, которое допускает развёртывание.

**Распределение**
: Решение валидатора о том, какой выход получает какую окрашенную величину.

**Обычное распределение**
: Поведение окрашивания по умолчанию, когда payload операции его не меняет.

**Сжигание**
: Окрашенная величина, которую не удалось поместить ни в один подходящий выход и которая поэтому уничтожается.

**Разделение**
: Операция `y`, разделяющая взаимозаменяемую величину на одном выходе.

**Пользовательское окрашивание**
: Операция `z`, зависящая от активации, явно назначающая окрашенную величину.

**splat**
: Операция `x` в невзаимозаменяемой ветви, разделяющая несколько Atomicals, находящихся на одном выходе.

**Проверка отсутствия инфляции**
: Правило, по которому окрашенные суммы выходов не могут превышать окрашенные суммы входов.

## Имена и коллекции

**Container**
: Именованный идентификатор коллекции, принадлежность к которой элементы могут доказать.

**DMINT**
: Децентрализованный выпуск элементов Container по запечатанному манифесту.

**Запечатывание**
: Приведение Atomical или манифеста Container в состояние, которое навсегда нельзя изменить.

**Realm**
: Имя Atomicals верхнего уровня, которым владеют как NFT.

**Subrealm**
: Дочернее имя, заявленное по правилам родительского Realm.

**Payname**
: Realm, используемый как адрес получения платежа.

**IDNA**
: Правила интернационализированных доменных имён, применяемые при сравнении и нормализации имён.

**Похожее имя**
: Два разных имени, которые отображаются достаточно похоже, чтобы ввести читателя в заблуждение.

## Интеграция

**Курсор**
: Непрозрачный подписанный токен постраничного вывода, указывающий на устойчивую позицию внутри поколения.

**Готовность**
: Может ли сервис прямо сейчас ответить корректно. Это не то же самое, что настроен или запущен.

**Свежесть**
: Насколько индекс отстаёт от вершины цепочки.

**Ключ идемпотентности**
: Ключ, задаваемый клиентом, который делает повторную отправку изменения безопасной.

**Идентификатор запроса**
: Идентификатор для каждого запроса, возвращаемый в ответах и логах, для отслеживания одного вызова.

**PSBT**
: Частично подписанная транзакция Bitcoin, формат обмена между сервисом и кошельком.

**BIP-322**
: Схема подписи сообщений, применяемая здесь для доказательства контроля над адресом без перемещения средств.

**SIGHASH**
: Флаг, определяющий, к каким частям транзакции относится подпись.
