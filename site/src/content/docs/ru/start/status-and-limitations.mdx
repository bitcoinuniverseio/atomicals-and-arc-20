## ARC-20

| Возможность | Состояние | Примечания |
| --- | --- | --- |
| Разрешение проверенного тикера и сведения о токене | Реализация Universe | Публикуется победивший Atomical ID, а не только имя |
| Снимки держателей | Реализация Universe | Строки держателей должны в точности давать оборотное предложение, иначе сканирование прерывается |
| История подтверждённой активности | Реализация Universe | Развёртывание, прямой и децентрализованный выпуск, перевод, сжигание, операции протокола |
| Покрытие ожидающей активности | Ограничено | Нет исчерпывающей ленты mempool со стабильной обработкой жизненного цикла ожидания |
| Балансы портфеля и окрашенные UTXO | Реализация Universe | Представления для чтения, не доказательство расчёта |
| Прямой выпуск `mint-ft` из продукта Universe | Не предоставляется | Протокол это поддерживает. Ни одна поверхность Universe этого не предлагает |
| Материал Substantiation Factor | Предварительный | См. [Substantiation Factor](/protocol/arc20/substantiation-factor/) |

<Aside type="caution" title="Заявленное покрытие намеренно частичное">
Источник ARC-20 сообщает покрытие `partial` с явной причиной: подтверждённая авторитетная история и
полные доказанные снимки держателей проиндексированы, но у поставляемого адаптера нет
исчерпывающей ленты mempool со стабильной обработкой жизненного цикла ожидания и исчезновения. Это
ограничение относится только к ожидающей активности. Оно не ослабляет подтверждённое сканирование и
требования к доказательству держателей.
</Aside>

## Atomicals NFT, Realm и Subrealm

| Возможность | Состояние | Примечания |
| --- | --- | --- |
| Модель чтения обычных NFT, Realm и Subrealm | Реализация Universe | Одно сканирование, поколение, контрольная точка и активный указатель |
| Разрешение Realm, иерархия и список Subrealm | Реализация Universe | Свидетельства кандидатуры и оплаты хранятся по каждому активу |
| Поиск по транзакции, блоку и UTXO | Реализация Universe | Ограничен активным поколением |
| Выдача медиа с проверкой целостности | Реализация Universe | Действуют ограничения MIME и по размеру |
| Взаимозаменяемые токены в этой проекции | Исключены по замыслу | Обслуживаются стороной ARC-20 |
| Containers и элементы DMINT в этой проекции | Исключены по замыслу | Заявлено в манифесте происхождения индекса |
| Операции записи | Отсутствуют | Проекция доступна только для чтения |

## Площадка

| Возможность | Состояние | Примечания |
| --- | --- | --- |
| Четыре изолированных протокольных полномочия | Реализация Universe | `arc20`, `atomicals_nft`, `realms`, `subrealms` |
| Объявление, резервирование, покупка, оферта, расчёт | Реализация Universe | Каждый шлюз действий по умолчанию выключен |
| Доказательство владения | Реализация Universe | Простое доказательство BIP-322 для P2WPKH и P2TR по ключевому пути |
| Смешанное обеспечение, сжигания, потраченные выходы, смещение контрольной точки | Отклоняются | Все четыре ветви завершаются отказом |
| Устаревшие псевдонимы `/buys` и `/orders/{orderId}/reconcile` | Устарели | Используйте `/reservations`, `/purchases`, `/settlements` |

## AVM

| Слой | Состояние |
| --- | --- |
| Архитектурные концепции из технического документа | Предложение |
| Официальный бета-интерпретатор | Экспериментальный или бета |
| Интеграция в среду выполнения Universe | Не предоставляется |
| Аттестация среды выполнения Universe | Не опубликована |

Ничто об AVM на этом сайте не следует читать как продакшн-поддержку в mainnet. См.
[состояние и ограничения AVM](/protocol/avm/status-and-limitations/).

## Известные нам ограничения

1. Ожидающая активность ARC-20 покрыта не исчерпывающе. Подтверждённая история покрыта.
2. Containers и DMINT задокументированы как поведение протокола. Ни одна проекция чтения Universe
   их сегодня не предоставляет.
3. Прямой выпуск FT это поведение протокола без продуктовой поверхности Universe.
4. AVM находится в бета-версии выше по цепочке и здесь не предоставляется. Любое заявление о
   реализации потребовало бы аттестации, которую мы не публиковали.
5. Некоторые сервисы экосистемы Atomicals, перечисленные в [реестре](/ecosystem/), не удалось
   проверить по доступному источнику. Такие строки указывают `unknown`, а не догадку.
6. Ограничения частоты документируются только там, где они действительно реализованы. Где сервис не
   имеет их вовсе, страница так и пишет, а не выдумывает политику.
