この用語集の語は、サイト全体とすべての翻訳で使われるものです。コードの識別子、スキーマのプロパティ
名、操作名、ハッシュは決して翻訳しません。

## 中核

**Atomical**
: Bitcoin のトランザクションによって作成され、Bitcoin の出力が保持するデジタルオブジェクト。

**Atomical ID**
: Atomical の恒久的な識別子。`<txid>i<出力インデックス>` の形式。一度割り当てられ、変わりません。

**Atomical 番号**
: 発行順に割り当てられる連番。表示に便利ですが、保存すべき識別子ではありません。

**所在**
: 現在その Atomical を保持している未使用出力。移動のたびに変わります。

**エンベロープ**
: reveal トランザクションのウィットネス内で `atom`、操作、CBOR ペイロードを運ぶスクリプト構造。

**操作**
: エンベロープ内の短いコードで、バリデータに何をするかを伝えます。例: `ft`、`dft`、`dmt`、`nft`、`mod`、`sl`。

**commit と reveal**
: 二段のトランザクション方式。commit が Taproot 出力に支払い、reveal がそれを使ってエンベロープを露出します。

**Bitwork**
: トランザクション ID に対するプルーフオブワーク形式の接頭辞要件。発行と請求を制限するために使われます。

**候補**
: グローバルに割り当てられる名前やティッカーに対する保留中の請求。ルールが勝者を決める前の状態。

**検証済みの勝者**
: ルールが名前やティッカーの保持者と判定した Atomical。

**世代**
: チェーン上の一貫した位置におけるインデックスの不変スナップショット。

**再編成**
: 既にインデックス化された結果を無効化しうる Bitcoin チェーンの再編成。

## ARC-20

**ARC-20**
: Atomicals の代替性トークンモデル。1 単位は 1 個の色付きサトシです。

**ティッカー**
: グローバルに割り当てられる ARC-20 の名前。作成者の身元の証明ではありません。

**色付き UTXO**
: バリデータが ARC-20 の価値を保持していると認識する Bitcoin の出力。

**カーディナル UTXO**
: Atomicals の価値を持たない通常の Bitcoin 出力。手数料とおつりに使います。

**直接 FT**
: 供給量全体を出力ゼロに置く一段階の `ft` 発行。

**DFT**
: `dft` で作成された分散型代替性トークンのデプロイ。

**DMT 請求**
: `dmt` 操作を用いた、DFT デプロイに対する 1 回の発行。

**恒久 DFT**
: 有効化に依存する分散型モード。Bitwork が進行し、任意で全体上限を持ちます。

**発行量**
: 有効な DMT 請求が出力ゼロに置く正確なサトシ額。

**最大発行回数**
: 固定モードのデプロイが許可する有効な請求の回数。

**割り当て**
: どの出力がどれだけの色付きの価値を受け取るかについてのバリデータの判断。

**通常割り当て**
: 操作ペイロードが変更しない場合の既定の着色挙動。

**焼失**
: 対象となるどの出力にも置けず、破棄される色付きの価値。

**分割**
: 一つの出力上で代替性の価値を分離する `y` 操作。

**カスタム着色**
: 有効化に依存する `z` 操作。色付きの価値を明示的に割り当てます。

**splat**
: 非代替性側の `x` 操作。一つの出力に保持された複数の Atomicals を分離します。

**非インフレ検証**
: 色付きの出力合計が色付きの入力合計を超えられないというルール。

## 名前とコレクション

**Container**
: アイテムが所属を証明できる名前付きコレクションの識別子。

**DMINT**
: 封印されたマニフェストに対する Container アイテムの分散発行。

**封印**
: Atomical や Container のマニフェストを恒久的に変更不能にすること。

**Realm**
: NFT として保有される最上位の Atomicals 名。

**Subrealm**
: 親 Realm のルールのもとで請求される子の名前。

**Payname**
: 支払い先として使われる Realm。

**IDNA**
: 名前の比較と正規化に用いる国際化ドメイン名の規則。

**紛らわしい名前**
: 読み手を欺くほど似て見える、異なる二つの名前。

## 連携

**カーソル**
: 世代内の安定した位置を指す、不透明で署名されたページングトークン。

**準備完了**
: サービスが今この瞬間に正しく応答できるかどうか。設定済みや稼働中とは別の概念です。

**鮮度**
: インデックスがチェーンの先端からどれだけ遅れているか。

**冪等キー**
: クライアントが指定する、変更操作の再送を安全にするためのキー。

**リクエスト ID**
: 応答とログに返される、1 回の呼び出しを追跡するためのリクエストごとの識別子。

**PSBT**
: 部分的に署名された Bitcoin トランザクション。サービスとウォレット間の交換形式です。

**BIP-322**
: 資金を動かさずにアドレスの管理を証明するために、ここで用いるメッセージ署名方式。

**SIGHASH**
: 署名がトランザクションのどの部分に対して確約するかを決めるフラグ。

## 使わない表現

次の語は第三者の資料に現れますが、このサイトでは主張として使いません。保証付き、リスクなし、
裏付けあり、担保付き、価格下限、償還。情報源がそれらを使っている場合は、その情報源を引用し、
どんな根拠があるかを明記します。
