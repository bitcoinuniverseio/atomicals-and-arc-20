    Changelog

    History of this documentation. Protocol rule changes are dated by Bitcoin activation height and listed on the specification page; this page tracks the documents themselves.

    2.0.0, 2026-09-01

    • Complete rebuild as a protocol dossier. Specification, guide, reference, test vectors, simulator, and changelog pages replace the previous single landing page.
    • Normative specification added, grounded in the Bitcoin Universe Atomicals indexer, a fork of atomicals-electrumx: envelope grammar, commit and reveal windows, CBOR payload requirements, ARC-20 coloring and splitting rules, dmint bitwork rules, and invalidity conditions, all as numbered rules.
    • ARC-20 transfer outcome simulator added: a client-side rule engine mirroring the indexer's FIFO ordering, output filling, split and custom color handling, the non-clean fallback, and burn accounting, with a step by step explanation.
    • Test vectors page added with valid and invalid cases, several transcribed from the indexer's own test suite.
    • Reference page added covering indexer semantics for confirmation, mempool, and reorg behavior, plus a list of Universe-specific indexing decisions kept separate from upstream protocol rules.
    • Product support matrix restricted to actions verifiable in Bitcoin Universe code, with the single-host order book durability limit and the open settlement reorg reconciliation item stated explicitly rather than glossed over.
    • Local search, dark and light themes, keyboard operability, and figure-style SVG diagrams introduced. The site works without JavaScript for all ordinary content.
    • Machine readable manifest, sitemap, robots.txt, and llms.txt added.
    • Accurate content preserved from the previous site: the one unit equals one satoshi model, UTXO ownership, the direct and decentralized issuance paths, the warning about keeping colored UTXOs intact before signing, the live ARC-20 workspace link, and the Atomicals CLI artwork credit.

    1.x, 2026-07-18 to 2026-08-19

    • 2026-08-19: described Universe-operated Atomicals production data behind the live ARC-20 workspace.
    • 2026-08-07: linked the live ARC-20 workspace in Bitcoin Inscribe.
    • 2026-07-30: reworked the landing page around the ownership journey.
    • 2026-07-18: first published pages for Atomicals and ARC-20 under this repository.
