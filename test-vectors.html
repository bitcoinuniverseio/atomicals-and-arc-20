Test vectors

Every row below is produced by running conformance/allocation.mjs, the port of the allocation rules from the pinned indexer revision. The expected values are not transcribed. They are what the engine returns, checked in CI, so a page that disagrees with the engine cannot be published.

Cases naming an upstream test correspond to a case in the indexer's own tests/lib/test_atomicals_blueprint_builder.py at the pinned revision.

Era is exact-cover for the rules before activation height 848484, where an output had to be fully covered or nothing was coloured, and current for the rules at or after it, where an output can be partially coloured.

Machine readable: arc20-allocation.json. Run them interactively in the allocation visualizer.
